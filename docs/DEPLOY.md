# Deploying FresherPilot (private, invite-only)

Two ways; both give you an HTTPS address like `https://jobs.<your-domain>` through **Cloudflare
Tunnel** (free; no router ports opened; the app itself only listens on 127.0.0.1).

| | A. Your PC | B. Oracle Cloud (always on) |
|---|---|---|
| Cost | free | free (Always Free VM; card needed to sign up) |
| Up when | your PC is on and awake | 24/7 |
| LinkedIn free reading | works (home IP) | may be blocked (cloud IP); other boards still work |

## 1. Google sign-in (both options, ~10 min)
1. https://console.cloud.google.com → new project → **APIs & Services → OAuth consent screen**:
   External, app name "FresherPilot", your email, links `https://<your-domain>/privacy` and
   `https://<your-domain>/terms`. Leave it in **Testing** and add each invitee's Gmail as a test user (up to 100).
2. **Credentials → Create credentials → OAuth client ID → Web application**. Authorized JavaScript
   origins: `https://<your-domain>` (and `http://localhost:8000` for local use).
3. In `.env` (copy `.env.example`): `GOOGLE_CLIENT_ID`, `FP_OWNER_EMAIL` (your Gmail), `FP_OPERATOR_NAME`,
   `FP_CONTACT_EMAIL`. `FP_SECRET_KEY` is generated by the server script (option B), or make one with
   `python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"`.

## 2. Cloudflare Tunnel token (both options)
You need a domain on Cloudflare (free plan is fine). Cloudflare dashboard → **Zero Trust → Networks →
Tunnels → Create a tunnel** (Cloudflared) → name it `fresherpilot` → copy the **token** → add a
**Public hostname**: `jobs.<your-domain>` → Service `http://localhost:8000`.

Recommended: **Zero Trust → Access → Applications** → add `jobs.<your-domain>` with a policy
"Emails: <your invitees>" (free up to 50 users), so strangers can't even reach the sign-in page.

## A. Run on your PC (Windows)
1. `winget install --id Cloudflare.cloudflared`, then once: `cloudflared service install <TOKEN>`
   (the tunnel then starts with Windows).
2. Start the app: `python main.py` (or `scripts\start_public.bat`). Keep the PC awake.

### Keep it running all the time (PC)
`powershell -ExecutionPolicy Bypass -File scripts\install_autostart.ps1` puts a shortcut in your Windows
Startup folder: at every sign-in a hidden watchdog (`scripts/keep_running.py`) starts the app and starts
it again within a minute if it stops (logs in `logs/`). The app keeps Windows from sleeping while it
runs and starts reading jobs + sending Telegram alerts by itself (no page needs to be open).
Stop: `scripts\stop.ps1`. Remove autostart: `install_autostart.ps1 -Remove`.
Laptop: Control Panel → Power Options → "Choose what closing the lid does" → *Do nothing* (plugged in).

Cloudflare Workers / Pages (`wrangler`) can't run FresherPilot: it is a long-running Python server
with background readers and local files, and LinkedIn blocks cloud IPs. Cloudflare's part is only the
Tunnel above (an address to reach the PC from your phone); Telegram alerts need no tunnel.

## B. Run on Oracle Cloud (24/7)
1. Sign up at https://cloud.oracle.com (Always Free). **Compute → Instances → Create**: image
   **Ubuntu 24.04**, shape **Ampere A1** (2 OCPU, 12 GB is plenty). If it says "out of capacity", try
   another availability domain or later. Save the SSH key it gives you.
2. Copy the project to the VM (from your PC, in the project folder):
   `scp -i <key> -r main.py fresherpilot web extension deploy docs requirements.txt .env.example ubuntu@<VM-IP>:~/fresherpilot/`
   To bring your existing accounts too, also copy `users` and `.env`.
3. On the VM: `ssh -i <key> ubuntu@<VM-IP>`, then
   `cd ~/fresherpilot && bash deploy/setup_server.sh <TUNNEL_TOKEN>`
4. Edit `~/fresherpilot/.env` (Google client ID etc.), then `sudo systemctl restart fresherpilot`.
5. Open `https://jobs.<your-domain>` and sign in.

Day to day: logs `journalctl -u fresherpilot -f` · restart `sudo systemctl restart fresherpilot` ·
after copying new code `bash deploy/update.sh` · backups: daily in `~/fresherpilot-backups` (14 days).

If LinkedIn shows "rate-limiting this computer" for hours on the VM, its cloud IP is blocked: the other
boards keep working; run the app on your PC (option A) if LinkedIn matters most.

## 3. Invite people
Sign in as the owner → **Settings → Invites** → add their Gmail addresses (and add them as test users
in the Google consent screen). They open your address, press **Continue with Google**, accept the
Terms, and the setup page walks them through: free Groq key → resume → cities → first fetch.
Remove a member in Settings to delete their account and data.

## 4. Browser extension (optional, each member)
For form autofill / auto-apply / Naukri sweep: load `extension/` in Chrome (Developer mode → Load
unpacked), set the server to `https://jobs.<your-domain>` in its popup, then open the app once.

## Notes
- Each member uses their own Groq (and optional Apify / NVIDIA / Gmail) keys; Apify's free $5/month covers Naukri.
- Health check URL for uptime monitors: `https://jobs.<your-domain>/api/health`.
- Legal: the Terms and Privacy pages are a solid base for a private app, not legal advice. Automated
  use of job sites and WhatsApp can break those sites' terms; members choose to use those features in
  their own browser, and the Terms say so.
